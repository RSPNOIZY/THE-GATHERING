## The hypothesis

> Compartmentalized building + seeing — treating each idea as a single-frame module with a clear door — is not a workaround for dyslexia. It is a superior cognitive architecture for complex systems design, which neurotypical tooling routinely degrades by collapsing multiple ideas into a single dense surface.

## Working thesis — three claims

1. **Containment reduces cognitive load.** One idea per surface means no working-memory tax from parallel scopes. Dyslexic cognition tolerates this badly; every brain tolerates it better.
2. **Seeing beats reading for architecture.** Spatial placement (a slide, a door, a diagram) encodes relationships dyslexic brains cannot easily encode in linear prose. For complex systems, this is a feature, not a crutch.
3. **Compartmentalization forces clean scopes.** The discipline cannot tolerate tangled modules — so the modules come out clean. Neurotypical builders can tangle things because they can hold the tangle in memory. That freedom produces tech debt.

If any of the three hold up under study, the deficit framing of dyslexia in systems work is factually wrong.

## Research questions

- Q1. Does compartmentalized tooling (alphabet doors + slide-per-idea + single-spotlight problem framing) measurably improve _output quality_ for dyslexic builders vs conventional tooling?
- Q2. Does the same tooling improve output quality for _non-dyslexic_ builders working on complex systems?
- Q3. Is the compartmentalized discipline teachable, or is it an emergent property of the specific dyslexic cognitive profile?
- Q4. What is the minimum viable tooling stack to reproduce the DreamChamber effect outside RSP's specific environment?
