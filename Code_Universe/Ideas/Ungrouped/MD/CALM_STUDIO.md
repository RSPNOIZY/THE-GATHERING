## What It Is

A caregiver-guided listening environment designed to support calm, sensory predictability, and nervous-system regulation.

**Explicitly non-clinical.** Not a medical device. Does not diagnose, treat, cure, or prevent any condition.

---

## The Landing Thesis

Calm Studio should feel like:
- A low-surprise listening space
- A caregiver-guided tool
- A safety-first companion
- A reflection loop, not a content treadmill

Most audio products optimize for engagement. Sensitive listeners need **predictability, bounded intensity, and fast exit paths**. Calm Studio optimizes for tolerance, not stimulation.

---

## Language Rules

**Use:** supportive listening / regulation-oriented environment / caregiver-guided calm sessions / sensory predictability

**Never use:** treatment / cure / diagnosis / autism healing

---

## Safety Controls (Mandatory)

- Max session length
- Daily max sessions
- Mandatory rest window
- Volume ceiling
- Soft start + soft end (locked ON)
- Mono-only option
- No whisper option
- No ASMR-triggers option

---

## User Roles

- Caregiver or parent
- Therapist or educator
- Self-use adult

---

## The NeuroAcoustic Safety Charter (Non-Negotiables)

1. **No cure claims** — no diagnosis, treatment, cure, or prevention without regulatory pathway
2. **Regulation support, not correction** — system supports calm and well-being; does not imply human difference should be normalized away
3. **Safety first for children** — caregiver controls, explicit stop, time-boxed sessions, mandatory rest, no autoplay, soft transitions
4. **No raw audio collection by default** — especially for children and sensitive users
5. **No silent pathology inference** — no diagnoses inferred from voice, behavior, or biosignals without proper framework
6. **Evidence labels visible** — every program declares: exploratory / research-informed / clinically evaluated
7. **Artist consent still applies** — creators can opt out of child-directed or sensitive contexts
8. **Community learning opt-in only**
