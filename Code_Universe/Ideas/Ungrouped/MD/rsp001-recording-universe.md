# RSP_001 Recording Universe
## Full Session Universe: Archetypes × Emotions × Contexts

This extends the base recording blueprint into a complete capture grid for Client#001.

## Target Structure

```
8 Archetypes
× 10 Emotions
× 6 Context Modes
= 480 directed performance units
```

## Capture Passes

### Pass A — Controlled Script
- fixed lines across all archetype/emotion/context combinations
- enables direct comparative QA

### Pass B — Semi-Directed
- same intent, variable wording
- captures natural cadence variance

### Pass C — Improvised
- free response with role constraints
- captures subtext, instinct, and recovery behavior

## Multilingual Seed Expansion

For each archetype/emotion pair, capture 6–30 sec seeds in each target language.

Minimum language pack:
- en, es, fr, de, ja, pt

Extended language pack can be added in separate sessions.

## QA Gates

1. Technical gate
   - no clipping
   - consistent room profile
2. Persona gate
   - archetype recognizable without visual cues
3. Emotional gate
   - emotion separable from neighboring states
4. Context gate
   - delivery matches context intent
5. Linguistic gate
   - pronunciation and rhythm meet language target

## Acceptance

A unit is accepted only when all five QA gates pass.

Units failing persona or linguistic gates are flagged for retake priority.
