# RSP_001 Full Recording Protocol
## Template for Guild Capture Sessions

This is the production protocol used for Client#001 and reused for all guild members.

## Session Goals

- Capture complete phonetic coverage.
- Capture broad emotional controllability.
- Capture reusable archetype personas.
- Capture multilingual seed anchors.

## Studio Standard

- 48kHz, 32-bit float
- Dry booth, no processing printed
- Low-noise chain, stable gain, no clipping
- Controlled hydration and pacing schedule

## Session Blocks

1. **Calibration Block**
   - baseline neutral reads
   - mic distance consistency markers

2. **Phoneme Block**
   - isolated phonemes
   - transition syllables
   - tongue-twister stress tests

3. **Emotion Block**
   - neutral / warm / threat / grief / command / whisper / sarcasm
   - same line across multiple emotional intents

4. **Archetype Block**
   - hero
   - villain
   - narrator
   - optional custom archetypes

5. **Multilingual Seed Block**
   - short canonical lines in target languages
   - dialect variants where required

6. **Improvisation Block**
   - unconstrained performance for cadence fingerprinting
   - spontaneous subtext and non-verbal cues

## File Hygiene

- deterministic naming convention
- immediate backup after each block
- session notes linked by take ID
- retake markers for QA

## Handoff Checklist

- all WAV masters exported
- notes + consent manifests attached
- ingest package validated
- upload to NOIZY pipeline
