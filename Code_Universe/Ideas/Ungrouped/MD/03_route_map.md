# Stage 03 — Route Map

## Goal

Define route ownership for both apps before page building begins.

## NOIZYFISH Routes

```
/                    → Landing, hero, featured works
/archive             → Filterable archive grid
/archive/[slug]      → Individual archive detail
/lineage             → Provenance philosophy
/about               → Mission, founder
/contact             → Contact info (optional)
```

## NOIZYVOX Routes

```
/                    → Landing, value proposition
/casting             → Voice discovery
/dashboard           → Creator command center
/consent             → Rights management
/onboarding          → 8-step enrollment
/trust               → Trust pillars
/about               → Mission, ecosystem
```

## Deliverables

- Route tree for both apps
- Layout ownership notes (root vs app-local layouts)
- App Router structure plan
- Static vs future dynamic notes
- `ROUTE_MAP.md` document

## Exit criteria

- Route ownership is clear
- Shared layouts are justified
- App-local layouts remain distinct
- Future dynamic paths are planned, not improvised later

## Checkpoint

After completion:

1. Confirm route tree is documented
2. State layout ownership decisions
3. Note any route changes from plan
4. Confirm readiness for Stage 04
