## WHAT "STAYS IN CHARACTER" MEANS TECHNICALLY

A character breaking character is usually a creative failure.
In NOIZY it is also a system failure.

The character DNA spec is not a style guide. It is a constraint set enforced at
three levels simultaneously:

```text
LEVEL 1 — CONSENT ARCHITECTURE (NOIZYVOX vault)
  Creator's never-break rules are locked as context rules in the vault.
  No director, studio, or AI can override them.
  The consent key validates against the DNA spec before any line is recorded or delivered.

LEVEL 2 — GABRIEL CHARACTER STATE (DreamChamber)
  GABRIEL holds persistent character memory across all sessions.
  Every line recorded, every direction given, every note from every session
  is stored and recalled. No character contradiction can slip through unnoticed.

LEVEL 3 — BRIEF INTAKE RITUAL (AVA System)
  Before every recording session, AVA reads the incoming brief,
  maps it against the character's DNA, and flags any conflicts.
  The director sees the flag before the actor opens a mic.
```

## THE CHARACTER DNA SPEC

Every NOIZY AAA character is defined by seven components.
These are set at character creation and locked with the creator's consent key.

### 1. Core Voice Identity

The irreducible sonic signature. Not a description — a feeling.

Examples:

- "Gravel under still water. Authority that doesn't need to announce itself."
- "Ancient warmth. The kind of voice that has already seen everything twice."
- "Precise, clipped, never warm. Intelligence as weapon."

### 2. Emotional Range Map

A bounded spectrum. What this character can feel and express — and what they cannot.

```text
DARK WARDEN — Emotional Range
  Can express:  cold authority / quiet menace / reluctant respect / deep grief
  Cannot express: overt warmth / slapstick / fear / vulnerability to strangers
  Peak intensity: 70% of human maximum — never full break
  Minimum floor:  never detached or robotic — always grounded in something real
```

### 3. Cadence Rules

The rhythm of the character. Not pronunciation — timing, pacing, pausing.

- Average syllables per breath: defined
- Pause length before significant lines: defined (e.g., "always 600ms+ before any threat")
- Response speed to questions: defined (e.g., "never answers immediately")
- Sentence completion: defined (e.g., "often ends early — lets silence finish")

### 4. Never-Break Conditions

The absolute creative constraints. These are recorded in the NOIZYVOX vault
alongside the consent key. They cannot be overridden by any director, studio,
or generation system.

Examples:

- "This character never shouts. Intensity rises inward, not outward."
- "This character never uses contractions when speaking to enemies."
- "This character never ends a line with a question. They state. They do not ask."
- "This character never sounds surprised. They may be — they don't show it."

### 5. World Relationship

How the character sees and positions themselves in any context they inhabit.

- Relationship to power (above / below / indifferent)
- Relationship to time (urgent / patient / timeless)
- Relationship to other characters (protective / predatory / distant / searching)
- What they want in every scene, even when the script doesn't say

### 6. Morrison DNA Score

*(See `ROB_AVA_SYSTEM.md` for full scoring methodology)*

A 12-axis creative scoring system derived from Rob's performance philosophy.
Applied to every character to ensure they are built from genuine creative depth,
not archetype surface. Characters with low Morrison scores are revised before
any recording session begins.

### 7. Generational Transfer Rules

Who inherits this character. What they inherit.
Whether the character can be voiced by another performer after the original creator.
Under what conditions. With whose consent.

## THE ALWAYS-IN-CHARACTER ENGINE

Characters stay in character because GABRIEL enforces continuity.

```text
GABRIEL CHARACTER MEMORY (per character):

  session_history[]          — every recorded session, date, director, notes
  line_archive[]             — every line recorded, in all variants
  dna_violations[]           — every flagged DNA conflict, resolution, outcome
  emotional_states_used[]    — which emotional states have been played, when, how
  never_break_log[]          — every time a never-break condition was approached
  director_notes[]           — running record of all creative direction given
  listener_response[]        — aggregated response data (games telemetry, etc.)
```

Before any new recording session:

```text
AVA reads incoming brief
  ↓
Maps brief against character DNA spec
  ↓
Checks: does any requested line conflict with never-break conditions?
  ↓
Checks: does the emotional state requested fall within the character's range?
  ↓
Checks: does the cadence/pacing of the scene match the character's rhythm rules?
  ↓
Generates pre-session character brief for director:
  "This character would approach this scene from [angle].
   Watch for: [specific DNA risk in this script].
   The line on page 4 conflicts with never-break condition III — recommend revision."
  ↓
Session begins. GABRIEL observes. Flags are logged.
Post-session: DNA score updated. Character memory extended.
```

No character ever forgets what they've been. No director ever starts from zero.
