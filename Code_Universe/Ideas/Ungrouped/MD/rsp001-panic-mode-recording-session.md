# RSP_001 Panic Mode Recording Session

## Objective

Produce protocol-grade prompt sets for Panic Mode:
- Box breathing
- 4-7-8 breathing
- Physiological sigh

## Capture Settings

- 48kHz, 32-bit float
- dry booth, no insert FX
- short phrase variants for:
  - neutral calm
  - assertive reassurance
  - low-stim sensory-safe tone

## Script Blocks

### Block A — Entry Safety Lines

- "I'm here with you."
- "You're safe right now."
- "We'll take this one breath at a time."

### Block B — Box Breathing (4-4-4-4)

- "Inhale for four."
- "Hold for four."
- "Exhale for four."
- "Hold for four."

### Block C — 4-7-8

- "Inhale for four."
- "Hold for seven."
- "Exhale for eight."

### Block D — Physiological Sigh

- "Deep inhale."
- "Small top-up inhale."
- "Long, slow exhale."

### Block E — Stabilization / Exit

- "Your body is slowing down."
- "Stay with this rhythm."
- "You're doing well."

## Performance Direction

- low arousal, no urgency
- short phrases, predictable cadence
- pause windows tuned for haptic pacing alignment

## Metadata Labels

- `protocol`: box | 4_7_8 | sigh
- `intensity`: low | medium | acute
- `profile`: standard | high_sensitivity | neurodiversity_support
- `language` + `dialect`

## QA

- no clipped consonants
- no abrupt transients
- timing tolerance within ±120 ms of pacing template
