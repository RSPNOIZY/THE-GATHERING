# NOIZYKIDZ Sleepy Time Variant (Child-Safe)

## Positioning

Child-focused sleep-support storytelling mode with strict safety defaults and non-commercial experience design.

This mode is **not medical care** and should never claim treatment/cure outcomes.

## Non-Negotiable Defaults

- Session duration cap on first run: `5–10 min`
- Hard volume ceiling enabled
- Soft start / soft end always on
- No abrupt transitions
- No autoplay chains
- Trigger intensity preset: low

## Child-Safe Audio Rules

- Disallow:
  - jumpy stereo movement
  - bright transient spikes
  - aggressive ASMR triggers
- Prefer:
  - neutral or warm narration
  - simple repeated phrases
  - low-complexity ambient textures

## Neurodiversity-Support Controls

Listener profiles can include:
- sound sensitivity
- startle tendency
- banned triggers
- preferred pacing

System response:
- suppress risky trigger categories
- reduce pace + dynamics
- shorten session length after activation reports

## Accessibility Modes

- Captioned story mode
- Haptic-friendly cue export (timing events for external devices)
- Voice-free ambient mode
- Mono compatibility option

## Data & Privacy

- No raw child audio collection by default
- Parent/caregiver opt-in for analytics only
- Export/delete controls visible and simple
- Parent/guardian attestation required for sharing

## Caregiver Check-In Model

After each session capture one outcome:
- calmer
- same
- activated
- overstimulated

Use these outcomes to tune future sessions safely.

## Compliance Guardrails

- COPPA-safe design for child-directed surfaces
- Explicit non-medical disclaimer on all sleep pages
- No targeted advertising in child mode

## Content Labeling

Each story must declare:
- age band
- sensory intensity
- trigger set
- runtime
- language/dialect
