# Stage 05 — NOIZYVOX Design System

## Goal

Forge the NOIZYVOX visual identity. Intimate. Futuristic. Trust-heavy. Creator-first.

## Brand Essence

- sovereign control
- ethical precision
- warm authority
- consequential hierarchy

## Deliverables

### Typography scale

- Display sizes for heroes
- Body sizes for content
- Metadata sizes for labels

### Color tokens

- Sovereign black
- Plum deep
- Voice violet (primary)
- Magenta (accents)
- Controlled glow (disciplined)

### Components

- Dashboard shell patterns
- Consent panel hierarchy
- Casting card system
- Onboarding step patterns
- Status chips (verified, pending, revoked, available)
- Button variants (voice, ghost, danger)
- Form inputs
- Activity timeline

### CSS/Tailwind

- `apps/noizyvox/app/globals.css` with design system classes
- Theme tokens in `packages/config/tailwind.config.js`

### Motion rules

- Subtle, intentional
- No crypto aesthetic
- No toy AI demo energy

## Exit criteria

- NOIZYVOX feels intimate and consequential
- UI feels creator-rights aware
- No visual bleed with NOIZYFISH
- Design system is documented in CSS

## Checkpoint

After completion:

1. List design files changed
2. Confirm brand separation from NOIZYFISH
3. State any design compromises
4. Confirm readiness for Stage 06
