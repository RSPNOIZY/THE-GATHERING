# NOIZYVOX AAA Studio Licensing Model
## Rights-Clear Access to Curated Voice Entities

## Licensing Tiers

### Tier A — Project License
- Single title or campaign.
- Fixed language set.
- Defined duration and media scope.

### Tier B — Franchise License
- Multi-title use under same franchise.
- Expanded language and character coverage.
- Priority support and custom adaptation.

### Tier C — Enterprise Runtime License
- Real-time integration for interactive systems (games/VR).
- High-volume render allowance.
- Regional compliance package and dedicated governance support.

## What Studios Receive

- Curated entity assets (not raw clone dumps).
- Character-consistent multilingual output.
- Consent and policy metadata with each asset.
- Traceable usage records.

## What Studios Do Not Receive

- Transfer of actor ownership.
- Unlimited unrestricted perpetuity by default.
- Rights beyond contracted scope.

## Rights Framework

- Actor remains source IP owner.
- Platform operates distribution and enforcement rails.
- Usage events are logged for royalty and dispute resolution.

## Economic Model (Default)

- 75% actor participation
- 25% platform participation

## Compliance Controls

- Category restrictions
- Geographic restrictions
- Political/advertising exclusions (if set by actor)
- Revocation workflow for future renders

## Studio Integration

- Deliverables: WAV assets + metadata manifests.
- API mode: controlled generation with policy checks.
- Runtime mode: approved profiles for interactive dialogue systems.
