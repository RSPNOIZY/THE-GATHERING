# NOIZYKIDZ Haptic Protocol (Non-Verbal + High-Sensitivity)

## Purpose

Child-safe haptic pacing profile for calming routines where voice-only guidance may be insufficient.

## Protocol Modes

1. `gentle_box`
- pattern: 4/4/4/4
- low intensity wrist/chest pulses

2. `long_exhale_support`
- pattern: 4/7/8
- emphasize exhale pulse extension

3. `grounding_pulse`
- slow distinct pulses
- present-moment anchoring

## Default Constraints

- intensity cap locked
- no abrupt motor ramps
- mandatory cooldown between sessions
- caregiver override always available

## Session Duration

- first sessions: 2–5 minutes
- expand only after repeated tolerance

## Outcome Logging

- calmer
- same
- activated
- overstimulated

Use outcomes to down-shift or up-shift protocol intensity.

## Accessibility

- supports no-audio mode
- supports captioned visual pacing
- supports caregiver-triggered activation

## Safety Language

Supportive regulation tool only; not a substitute for medical or emergency care.
